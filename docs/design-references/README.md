# Design References

This folder contains design reference images, mockups, and inspiration for application UI/UX updates.

## Organization

You can organize files by:
- **Feature**: `login-redesign/`, `form-layout/`, `dashboard/`
- **Type**: `mockups/`, `inspiration/`, `color-schemes/`
- **Date**: `2025-10-11-navigation-update/`

## Usage

1. Download reference images here
2. Reference them in your conversations with Claude Code
3. Use them to guide design implementation decisions

## Notes

- Keep file names descriptive: `dashboard-card-layout-v2.png`
- Add notes in this README about specific design decisions
- Consider using subdirectories for different features or versions
